GRADIUS NEO – Batocera 41 package

Installation:
1. Copy this entire folder to:
   /userdata/roms/pygame/gradius-neo
2. Copy your unmodified original game file into:
   /userdata/roms/pygame/gradius-neo/roms/gradius_neo_176x220-71722.jar
   The JAR is required and is deliberately not included in this package.
3. In Batocera, update the game list or restart EmulationStation.
4. Launch "gradius-neo" from the Pygame system.

Controller:
  D-pad / left stick  Move
  A                   Fire / confirm
  B or L1             Left power-up (Q)
  X or R1             Right power-up (W)
  L2                  Video filter
  Start               Pause
  Select              Back
  Hotkey + Start      Exit to Batocera

Required ROM:
  roms/gradius_neo_176x220-71722.jar
  SHA-256: 714701042f16190916e5ea977408f8f4c9b3b0d5928cba301ad52aef0f17c12d

Save data:
  /userdata/saves/pygame/gradius-neo

Troubleshooting logs:
  /userdata/system/logs/es_launch_stderr.log
  /userdata/system/logs/es_launch_stdout.log

GRADIUS NEO – Windows J2ME Emulator package

Required original ROM:
  Copy your unmodified original game archive to:

  roms\gradius_neo_176x220-71722.jar

  Expected SHA-256:
  714701042f16190916e5ea977408f8f4c9b3b0d5928cba301ad52aef0f17c12d

  The ROM is deliberately not included. The emulator will not start without it.

Controls:
  Arrow keys       Move
  Space / Enter    Fire / confirm
  Q                Left power-up
  W                Right power-up
  P                Pause
  Escape           Back
  F1               Video filter
  F2               Screen size: 2x / 3x / full height
  Alt+Enter        Toggle fullscreen

Gamepad (SDL/XInput, including 8BitDo SN30 Pro):
  D-pad / left stick  Move
  A                   Fire / confirm
  B                   Left power-up
  X                   Right power-up
  Back / Select       Back
  Start               Pause
  Left shoulder       Video filter
  Right shoulder      Screen size

Save data:
  saves\
